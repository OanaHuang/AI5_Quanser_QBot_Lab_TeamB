AI5 Quanser QBot Lab - Team B

This repository contains the project materials for Team B in the Advanced AI 5 course at the University of Glasgow.

We are students from the Robotics & AI programme. This project is based on the Quanser QBot laboratory experiment, where we use a Convolutional Neural Network (CNN) to train the robot car for vision-based control.

Project Overview

The aim of this project is to apply AI-based methods to the Quanser QBot platform. In particular, we focus on using CNN models to process visual input and support autonomous vehicle control.

At the same time, we also retain the original DIP control implementation as a baseline and reference method. This allows us to compare the traditional control approach with the CNN-based learning approach.
