# AI5 Quanser QBot Lab - Team B

This repository contains the work of **Team B** for the **Advanced AI 5** course at the **University of Glasgow**.

We are students from the **Robotics & AI** programme. This project is based on the **Quanser QBot lab**, where we trained a robot car using a **CNN model**. The original **DIP control** files are also kept in this repository as a reference.

## Project Content

This repository includes:

- CNN model files
- Training and testing scripts
- Dataset summary
- Final report materials
- Presentation slides
- Project notes
- Original DIP control files
